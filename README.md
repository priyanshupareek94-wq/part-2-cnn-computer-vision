Task 6: CNN Concepts Explained
- Convolutional Layers: These layers use filters to extract features like edges and textures from images.
- Pooling Layers: Max Pooling is used to reduce the data size while keeping important features, making the model faster.
- Flattening: Converts 2D image data into a 1D vector to be processed by the final classification layers.
- Dense Layers: The final layers that classify the image into one of the four defect categories.
